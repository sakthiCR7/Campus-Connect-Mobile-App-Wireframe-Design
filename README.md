# Campus Connect Mobile App Wireframe

## Overview
Campus Connect is a student activity and event management mobile application designed to simplify event discovery, registration, and communication for college students.

## Internship Assignment
This project was completed as my first internship assignment focused on mobile app wireframing and UX design.

## Key Activities
- User Research
- User Persona Creation
- User Flow Design
- Low-Fidelity Wireframing
- Design Thinking Process

## Tools Used
- Figma
- GitHub

## Outcome
Successfully designed a complete wireframe solution and gained hands-on experience in user-centered design, information architecture, and mobile UX planning.
